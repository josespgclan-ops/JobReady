# JobReady Landing Page

Landing page oficial de JobReady: una plataforma para practicar entrevistas profesionales y recibir retroalimentación de evaluadores.

## Sitio publicado

La versión pública se despliega mediante GitHub Pages.

## Tecnologías

- HTML5 semántico
- CSS3 responsive
- JavaScript
- GitHub Pages

## Probar localmente

Desde la carpeta `frontend`, ejecutar:

```powershell
python -m http.server 5500
```

Luego abrir `http://localhost:5500`.

> No abras `index.html` con doble clic si después conectarás la API. Servirlo por HTTP evita problemas de rutas y CORS.
